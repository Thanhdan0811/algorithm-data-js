

# null constanst
```
$x = NULL | null;

echo $x; // => empty
var_dump($x) // NULL
var_dum(is_null($x)); // true

```

# Biến ko đc khai báo sẽ là null

# unset($x) sẽ thành null, xóa biến.

# isset($x) check xem biến có tồn tại không ?

# empty($x) kiểm tra biến có rỗng không, rỗng trả về true (''), không tồn tại trả về true,  
- các giá trị true : không tồn tại biến, '', '0', 0, false, -0, null
